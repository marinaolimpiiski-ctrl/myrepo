# что делает проект? 
README.md — первый файл, который видит пользователь. Проверяющему понятно, какую задачу решает данный проект и какой результат ожидается.
# где notebook, данные и отчет? 
notebook находиться в папке notebooks/ или в корне, если их 1-2
данные находятся в папке data/. это большие файлы 50-100мб, которые находятся в git lfs или хранят в облаке, а в репозитории оставляют только маленькие примеры. 
отчет находится в reports/ или как отдельный .md в корне. 
# что сделать проверяющему? 
проверяющий может открыть репозиторий в браузере. файлы .md и .inpynd видны на сайте. главное дать проверяющему ссылку на репозиторий
# как понять, что все работает? 
1. запускается без ошибок
2. результаты воспроизводимы
3. данные доступны
4. есть отчет
# что не проверяется или может сломаться? 
1. если файлы больше 100мб, то проверяющему придется отдельно их скачивать
2. не все тесты есть
3. устаревшие зависимости
